Test Config — JSON Reference Decoder

Test-IDs · Group-IDs · Cadence-IDs · Thresholds · rx_limits — what every field means

Frequency point meanings (fm / fb / ft)
fm — mid-band
Channel center frequency
The nominal center of the operating band. For B3: 1800 MHz DL. This is the most representative operating frequency. All CI and smoke tests use fm only — fewest variables, fastest result.
fb — band-bottom
Lower band edge frequency
First channel in the operating band. Most affected by the high-pass response of the band-select filter. RSSI accuracy and blocking tests at fb reveal filter roll-off effects on receiver performance.
ft — band-top
Upper band edge frequency
Last channel in the operating band. Affected by the low-pass response of the band-select filter. Together fb/fm/ft give full coverage of performance variation across the band.
ETM — E-UTRA Test Model meanings
ETM 1.1
Full allocation 64QAM
All resource blocks allocated, 64QAM modulation, full power. Used for ACLR, EVM, output power — represents peak stress on the PA and spectral performance.
ETM 2a
Partial allocation
Sub-set of RBs allocated. Used for dynamic range tests where partial loading is required. Also used for time offset testing to see offset behavior under partial load.
ETM 3.1a
Multi-antenna reference signal
Includes cell-specific reference signals across multiple antenna ports. Used for EVM and ACLR OTA tests — the reference signal structure is needed for beam coherence measurements.

Tx test deep-dive — downlink (base station transmit)
test_Tx_BS_Output_Power
BS output power accuracy
Verifies RU transmits at declared output power within ±1.5 dB tolerance (normal conditions) or ±3.2 dB (extreme). Measured using EXM channel power measurement at fm.
Normal band 0–3 GHz: pass ±1.5 dB · extreme: ±3.2 dB
Normal band 3–4.2 GHz: pass ±1.5 dB · extreme: ±3.5 dB
Tolerance from your RRH-Thresholds config: channelPower normal band_0_3000: min -1.5 max +1.5
test_Tx_EVM
Error vector magnitude
Modulation quality. 3GPP TS 36.141 limits per ETM: ETM 1.1 tests 64QAM EVM. Measured at fm. Also run OTA (test_Tx_EVM_OTA) for ETM 3.1a.
QPSK: ≤ 17.5% EVM
16QAM: ≤ 12.5% EVM
64QAM: ≤ 8% EVM
test_Tx_ACLR
Adjacent channel leakage ratio
How much TX power leaks into adjacent LTE/UTRA channels. Most frequently run test (CI, Nightly, Regression, Sanity). ETM 1.1, fm.
E-UTRA ACLR ≥ 45 dBc (±1 carrier offset)
UTRA ACLR ≥ 50 dBc (±5/10 MHz offset)
Also runs OTA (test_Tx_ACLR_OTA) at ETM 3.1a. OTA ACLR accounts for beam pattern effects.
test_Tx_FrequencyError
Carrier frequency error
How accurately the RU hits the target center frequency. 3GPP limit: ±0.05 ppm (Wide Area BS). At B3 (1800 MHz) that's ±90 Hz. Caused by oscillator drift, temperature, aging.
Wide Area BS: ±0.05 ppm
Local Area BS: ±0.1 ppm
test_Tx_time_offset
Transmit time offset
Timing accuracy of the transmitted frame vs. expected timing reference. Runs at ETM 1.1, 2a, and 3.1a — broadest ETM coverage of any single test. fm only.
test_lte_Tx_Mask
Spectrum emission mask (SEM)
Checks TX spectrum against 3GPP emission mask out to ±30 MHz and beyond the carrier. ETM 1.1 and 1.2. Broader than ACLR — covers all out-of-band emissions.
SEM failures can cause regulatory non-compliance — blocks deployment approval.
test_lte_Tx_Spurious
Transmitter spurious emissions
Measures harmonic and intermodulation products appearing outside the operating band. TS 36.141 clause checked by spectrum sweep across 30 MHz–12.75 GHz range.
test_Tx_dynamic_range
Output power dynamic range
Tests the RU can accurately produce power from maximum down to minimum (−6 dB, −10 dB, etc.). ETM 2a, 3.1a, 2.0, 3.1. Nightly and Sanity only. Verifies PA linearity across its range.
test_Tx_DLRS
Downlink reference signal quality
Checks the Cell Reference Signal (CRS) EVM and power accuracy. ETM 1.1 only. CRS must be accurate for UE channel estimation — degraded CRS = UE cannot decode DL data.
test_Tx_TimeAlignment
Time alignment error (TAE)
For multi-antenna MIMO: maximum timing difference between antenna branches. 3GPP limit: ≤ 65 ns (intra-band) for release 8+. Critical for MIMO spatial multiplexing quality.
test_Tx_modulation_analysis
Modulation analysis bundle
Compound test = [Output Power + EVM + Freq Error + DLRS + time offset] in one run. Used in Nightly and Sanity. Efficient: 5 measurements from one captured waveform.
Rx test deep-dive — uplink (base station receive)
test_Rx_Reference_Sensitivity_Level
Reference sensitivity (REFSENS)
The minimum signal level the RU can correctly receive. 3GPP defines this as the power level at which PUSCH throughput ≥ 95% of max for a fixed reference channel (FRC).
Wide Area BS: −69 dBm (1.4/3/5/10/15/20 MHz) — from your rx_limits_validation_conditions
Test signal: PUSCH QPSK, 1 layer, specific FRC
Channel: AWGN (baseline), EPA5, EVA70 for fading
Most critical UL test. If REFSENS fails, coverage shrinks — cell edge users cannot connect.
test_Rx_RSSI
Received signal strength indicator
Verifies the RU accurately reports RSSI — the total received power across the channel bandwidth including signal, interference, and noise.
Measured at fm (mid-band frequency)
Compared against expected value with ±2 dB typical tolerance
test_Rx_RSSI_Accuracy
RSSI accuracy at band edge
Tests RSSI accuracy specifically at fb (band-edge frequency) — where filter roll-off causes the most measurement error. P5 cadence only. ETM 1.1.
Band-edge is hardest: filter response is not flat, RU must still accurately report RSSI within spec. Most RUs show highest RSSI error here.
test_lte_Rx_ACS
Adjacent channel selectivity (ACS)
RU's ability to receive a wanted signal in the presence of a strong adjacent channel interferer. Tests all 3 frequency points (fb/fm/ft). Signal is on wanted channel, interferer is ±1 channel offset.
Wanted signal at REFSENS + 3 dB
Interferer: +16 dB above wanted signal (adjacent channel)
Pass: throughput ≥ 95% of max
test_lte_Rx_ICS
In-channel selectivity (ICS)
Ability to receive a weak wanted resource block allocation in the presence of a strong interferer within the same channel bandwidth. Tests all 3 freq points.
test_lte_Rx_NB_blocking
Narrowband blocking
RU must correctly receive wanted signal when a strong CW (narrowband) interferer is present just outside the operating band. Tests fb/fm/ft. Models real-world out-of-band interference.
test_lte_Rx_blocking
In-band blocking
Blocking by a strong signal anywhere within the operating band but on a different channel. fm only. Tests AGC and front-end linearity when a nearby strong signal is present.
test_lte_Rx_intermodulation
Receiver intermodulation
Two interfering signals create an intermodulation product that falls on the wanted signal's frequency. Tests the RU receiver's third-order intercept point (IIP3) — a measure of linearity.
Two interferers: f1 and f2, spaced so 2f1−f2 or 2f2−f1 falls on wanted channel
Tests fb/fm/ft

OTA

NR OTA Tests — TS 38.141-2 (Radiated Conformance)

Massive MIMO / AAS base stations · EIRP · TRP · EIS · CATR anechoic chamber · FR1 (sub-6 GHz)

OTA testing fundamentals — before any test
WHY OTA?
Why radiated testing exists
Modern 5G NR massive MIMO (AAS — Active Antenna Systems) has the antenna array integrated inside the RU with no external RF connectors. You cannot plug in a cable to the antenna port. The only way to measure the RU's radiated performance is over the air.
Your RU (Metro AAU) is exactly this type — the 3GPP calls it BS Type 1-O (FR1 OTA only) or BS Type 1-H (hybrid — some conducted TAB connectors + OTA at RIB).
EIRP
Effective isotropic radiated power
The power that a hypothetical isotropic (radiating equally in all directions) antenna would need to emit to match the power the DUT radiates in its peak beam direction. EIRP = TX Power + Antenna Gain.
Measured in the far field in the beam peak direction
Units: dBm (absolute) or dBi relative to isotropic
Used for TX conformance: output power, ACLR, EVM
TRP
Total radiated power
Integral of radiated power over the entire sphere (all angles). TRP is lower than peak EIRP — it captures the efficiency of the whole antenna pattern. Requires 3D sphere scan.
TRP = sum of EIRP in all measured directions, weighted by solid angle
Radiated transmit power test (TS 38.141-2 §6.2)
EIS
Effective isotropic sensitivity
Minimum signal power density (W/m²) from a far-field source that the receiver can successfully decode. EIS is the OTA analogue of conducted REFSENS. Lower EIS = more sensitive receiver.
Used for RX conformance: sensitivity, ACS, blocking
Measured in beam peak direction
CATR
Compact antenna test range
The anechoic chamber method used for OTA testing. A parabolic reflector converts the near-field spherical wave from a feed antenna into a plane wave (far-field equivalent) in a much shorter distance. The quiet zone (QZ) is where the DUT sits.
Far-field distance = 2D²/λ. At 2 GHz a 30 cm array needs 60m — CATR reduces this to 2-3m
3GPP-approved method per TR 38.810
BS TYPES
3GPP base station type taxonomy
3GPP defines which test standard applies based on BS type. Your Metro AAU is most likely Type 1-H or 1-O.
Type 1-C: conducted only (traditional macro BTS with external antenna) → TS 38.141-1
Type 1-H: hybrid — has TAB connectors AND OTA RIB → both TS 38.141-1 and 38.141-2
Type 1-O: FR1, OTA only, no connectors → TS 38.141-2 only
Type 2-O: FR2 (mmWave), OTA only → TS 38.141-2 only
OTA transmitter tests — TS 38.141-2 Chapter 6
§6.2 — Radiated TX Power
OTA base station output power (TRP)
Measures total radiated power across the full sphere. Compares measured TRP against the manufacturer's declared TRP value within the specified accuracy window. Requires full 3D sphere measurement.
Declared EIRP per beam identity and beam direction pair
Rated beam EIRP = max power at beam peak direction
Accuracy window specified per operating band in TS 38.104
§6.3 — OTA Output Power
OTA base station output power (EIRP)
Measured at the beam peak direction using EIRP. Verifies the RU hits its declared EIRP within the specified tolerance. Single direction measurement — faster than TRP but less complete.
Test at declared beam peak direction
EIRP tolerance: typically ±3 dB for normal conditions
§6.4 — Output Power Dynamics
OTA output power dynamics
Tests accurate power control across the full dynamic range. RU must hit target power at all levels from maximum down to minimum (−6/−10/−30 dB below max). Tests PA linearity and power control accuracy.
On/off power ratio: ratio of TX-ON to TX-OFF power level
Transient period: time for power to ramp up/down within spec
§6.5.1 — OTA Frequency Error
OTA carrier frequency accuracy
Same concept as conducted freq error but measured OTA. The radiated carrier must be within ±0.05 ppm of the declared frequency. Measured by demodulating the received OFDM signal and comparing subcarrier positions to nominal.
Wide Area BS: ±0.05 ppm (same as conducted)
At 3.5 GHz: ±0.05 ppm = ±175 Hz
§6.5.2 — OTA EVM
OTA error vector magnitude
Modulation quality measured OTA in the beam peak direction. Uses a probe antenna in the CATR quiet zone connected to the signal analyzer. Same EVM limits as conducted, but now includes antenna array effects.
QPSK: ≤ 17.5% · 16QAM: ≤ 12.5% · 64QAM: ≤ 8%
256QAM: ≤ 3.5% (where supported)
Uses NR test models (NR-TM 1.1, 2, 3.1 etc.)
§6.5.3 — OTA TAE
OTA time alignment error
Maximum timing difference between antenna branches, measured OTA. For AAS systems the timing of all antenna elements must be coordinated for correct beamforming. TAE error degrades MIMO and beamforming gain.
Intra-band: ≤ 65 ns (Rel-15/16)
Measured between beam pairs at known angular positions
§6.6.2 — OTA OBW
OTA occupied bandwidth
Bandwidth containing 99% of total radiated power. Must remain within the allocated channel bandwidth. For a 100 MHz NR channel: OBW ≤ 99 MHz (leaving 0.5 MHz guard each side).
§6.6.3 — OTA ACLR
OTA adjacent channel leakage ratio
Measured OTA in beam peak direction. Power leaking into adjacent NR/LTE channels. Adds beamforming pattern effects on top of conducted PA nonlinearity.
NR ACLR: ≥ 45 dBc (sub-6 GHz)
UTRA ACLR: ≥ 45 dBc
§6.6.4 — OTA OBUE
OTA operating band unwanted emissions
Spectrum emission mask measured OTA — checks unwanted emissions across the operating band from the carrier edge out to the channel edge. Tests the overall spectral cleanliness of the radiated signal.
§6.6.5 — OTA Spurious
OTA transmitter spurious emissions
Harmonic and intermodulation products measured OTA across the full spurious domain (9 kHz–12.75 GHz). These can interfere with completely different services (GPS, aviation, emergency services). Strict absolute power limits.
§6.7 — OTA Tx Intermod
OTA transmitter intermodulation
A second signal is injected into the RU transmitter path. The resulting intermodulation products (2f1−f2, etc.) are measured OTA. Tests PA linearity when the antenna port faces a strong reflected signal (antenna mismatch or nearby transmitter).
Requires a second signal generator injecting into the antenna port — different test setup from all other TX tests.
OTA receiver tests — TS 38.141-2 Chapter 7
§7.2 — OTA Sensitivity
OTA reference sensitivity (EIS)
OTA equivalent of conducted REFSENS. The signal generator illuminates the RU via a probe antenna in the CATR. Level is swept down until PUSCH throughput falls below 95%. The level at which this happens (expressed as EIS in dBm/m²) is the sensitivity.
EIS = EIRP of source − path gain + DUT sensitivity angle correction
Measured in beam peak direction
Equivalent to conducted: −69 dBm for Wide Area BS
This is the single hardest OTA test to pass — any beamforming loss, PA noise leakage, or antenna inefficiency shows up directly as degraded EIS.
§7.3 — OTA Dynamic Range
OTA receiver dynamic range
Tests the RU can receive correctly when a strong in-band signal is present simultaneously. AGC must handle the level difference. Measured OTA with wanted signal and interferer both transmitted from the CATR.
§7.4/7.5 — OTA ACS/IB Blocking
OTA in-band selectivity and blocking
ACS: wanted signal + adjacent channel interferer transmitted simultaneously from different angles (DFF chamber) or same angle (CATR). RU must correctly receive the wanted signal at 95% throughput.
Wanted: fm at REFSENS + 3 dB
Interferer: +16 dBm above wanted, ±1 channel offset
§7.6 — OTA OOB Blocking
OTA out-of-band blocking
Strong CW interferer well outside the operating band. Tests the RU receiver front-end filter rejection. If the filter is inadequate, the interferer desensitizes the LNA or saturates the ADC.
§7.7 — OTA Rx Spurious
OTA receiver spurious emissions
The RU receiver can itself radiate spurious signals via the antenna (LO leakage, oscillator harmonics). These must be below specified absolute limits. Unique to OTA — the antenna is radiating these spurious signals into free space.
§7.8 — OTA Rx Intermod
OTA receiver intermodulation
Two strong interferers at f1 and f2 create an intermodulation product at 2f1−f2 that falls on the wanted channel. Tests RU receiver front-end IIP3. Critical for deployments near existing base stations on adjacent bands.

RSSI ADC calibration results — actual data from your units

What this document contains:
Per-unit, per-band, per-column ADC_ADJUST values measured during factory calibration. Shows pre- and post-calibration RSSI error for units 26050508 and 26050509. Reference for expected ADC_ADJUST ranges per band — if a field-measured value deviates > 3 dB from factory, the RU has drifted and needs recalibration.
How to use this data:
Compare your get_rssi readings against the factory ADC_ADJUST baseline. Systematic offset = ADC_ADJUST wrong. Per-column variation > 3 dB from others = that column has hardware issue. Temperature-correlated drift = TEMP_COMP table needs updating.

Calibration procedure (verbatim from the deck)
The calculation of the required offset correction was done by setting a known power level at the signal generator, measuring the RSSI that is read, and repeating the process for 3 different power levels. Measurements were done using a CW tone at the center frequency of each band.
After 3 measurements, an approximated linear line is fitted and an average offset is determined. This offset is written to /etc/configs/hardware.json — the ADC_ADJUST vector, one entry per ADC (0–7). Then automation sweeps: [-40 dBm : 1 dB step : -120 dBm]

2 dB error margin = the power level at which the RSSI reading deviates from the linear fit by 2 dB. PA efficiency test plan — 5-band AAU, Dynamic Vdd

PA efficiency test method:
Measure DC input power (V × I) and RF output power simultaneously. Efficiency = P_RF_out / P_DC_in × 100%. Test at: rated power, 3 dB backoff, 6 dB backoff. Repeat with Dynamic Vdd enabled and disabled. Expected: Dynamic Vdd improves average efficiency by 10–15 percentage points at 6 dB backoff.
Dynamic Vdd step configuration:
Vdd steps are configured in the PA_VDD_TABLE register. Each step corresponds to an output power range. Number of steps and threshold power levels are configurable. More steps = smoother efficiency curve but more switching transients. Typical: 4–8 steps from minimum Vdd (low power) to maximum Vdd (rated power).

Measurement procedure (B1B3 example)
Vdd_Nominal = 40 V: Measure ACLR/EVM/Tx Power at 100%, 50%, 30%, 0% occupancy — this is the reference.
Vdd_Low1 = 32 V, Occupancy = 50%: Compensate CFR and adjust Tx power via DAC Current to match 40 V reference. Measure 50%, 30%, 0% occupancy.
Vdd_Low2 = 25 V, Occupancy = 50%: Same — compensate CFR + DAC, measure all occupancies.
For each Vdd point: measure current from main PSU (−48 V), PSU #1–3, DC-DC converters (via CB-MCU). Calculate drain efficiency = RF power out / DC power in.
Also measure: temperature sensors (FHGW / RFFE / Common-Board). Verify ACLR/EVM stay within 3GPP spec throughout all Vdd transitions.
What the measurements prove
Beamforming gain verification: at coherent phases across all elements, verify ~+12 dB gain for B1/B3/B41 (12-element arrays) and ~+6 dB for B8/B28 (6-element arrays) relative to single PA TX power. This is the antenna array gain in action — phase alignment across all branches producing constructive interference in the beam direction.

FHGW embedded RCT — standalone UL test, CLI commands

FHGW standalone mode:
FHGW can run a subset of RCT without full DU connection. In this mode: FHGW generates its own timing, enables RU RF, configures EXM via SCPI, reads get_rssi, and compares against embedded limits. Useful for: initial hardware bring-up, field deployment without full lab setup, quick smoke test.
Key CLI commands in FHGW mode:
fhgw_rct start --band B1 --bw 10M: starts embedded RCT for B1.
fhgw_rct status: shows current test progress.
fhgw_rct results: prints PASS/FAIL per test case.
fhgw_rf_enable B1: enables B1 RF path.
fhgw_exm_set --freq 1950e6 --power -95: configures EXM.
Why it exists
Traditional UL RCT needs: DU + PHY Docker + FHSRV Docker + RU + signal generator + grandmaster + networking. The embedded RCT removes everything except the RU and signal generator. One CLI command. Catches RX-chain regressions at the box level, fast, before DU integration.
Prerequisites
FHGW with embedded RCT firmware image (includes ru-ulsim and ru-dvt-cli)
Signal generator with 3GPP FRC waveforms (A1-3, A3-x, A5-x at target bandwidth)
RF cabling from signal generator to target antenna port
NO DU required · NO external test PC required for execution · NO external test scripts

VID1 Constellation Diagram Diagnosis — reading impairments from IQ plots (YouTube aQd_zBytid8) Intermediate click to expand▾

Constellation diagram diagnosis — reading IQ impairments

Constellation shape → root cause:
Tight clusters at ideal points: excellent EVM, all good. Spread/fuzzy clusters: phase noise (LO quality) or thermal noise (SNR too low). Offset from grid: DC offset / LO leakage. One axis compressed: IQ amplitude imbalance. Grid rotated: IQ phase imbalance. All points compressed inward: PA compression (DPD failure or over-driven). Asymmetric spread: phase noise on one sideband (LO filtering issue).
EVM floor — what sets it:
Phase noise: LO quality sets the irreducible EVM floor regardless of SNR. Better SNR will not improve EVM once phase-noise-limited. Quantisation: 12-bit ADC SQNR = 74 dB → EVM floor from ADC ≈ 0.02% (negligible). Nonlinearity: P1dB compression → EVM increases sharply. At rated power with DPD: EVM < 3% typically. Without DPD: EVM > 10%.
▶ Watch: Interpreting Constellation Diagrams (YouTube) — covers how to diagnose signal impairments from the IQ scatter plot. Here is everything the video teaches, applied to your EXM and RU work.
What a constellation diagram is
A constellation diagram plots received IQ samples as dots on a 2D plane. The ideal symbol positions are shown as reference points (circles or crosses). Every received sample should land exactly on an ideal point. The spread, shape, and position of the cloud around each ideal point tells you exactly what is wrong with the signal.
How to read it on your EXM
On the E6640A EXM: Meas → EVM → Display → Constellation. You see all received symbols as dots. Perfect signal: tight clusters at each constellation point. Impaired signal: clouds, rings, rotations, or asymmetric spreads.

EVM floor breakdown (what limits your minimum EVM)
Total EVM² = EVM_noise² + EVM_phase² + EVM_IQ² + EVM_BFP² + EVM_DPD² EVM_noise: from thermal noise and receiver NF EVM_phase: from LO phase noise (at subcarrier offsets within channel BW) EVM_IQ: from IQ imbalance (gain + phase mismatch) EVM_BFP: from BFP compression in eCPRI fronthaul (~0.1–0.3%) EVM_DPD: residual from imperfect DPD model Practical floor: a perfectly calibrated system still has ~0.3–0.5% EVM from noise + BFP alone. If you see EVM > 1% with everything calibrated → DPD or PA issue.
When EVM is exactly at the 3GPP limit (e.g. 8% for 64QAM) — reduce TX power by 3 dB. If EVM drops significantly → PA compression. If EVM stays the same → noise or IQ calibration issue.

Common ACLR measurement errors:
Preamp ON with TX signal → input compresses → ACLR appears 10 dB better than reality (false pass). Insufficient attenuation → same error. Not waiting for DPD → ACLR is 10–15 dB worse than final (false fail or premature debugging). Wrong channel BW setting → integration bands wrong → wrong result. Always double-check: atten total, preamp OFF, DPD converged, correct channel BW.
▶ Watch: Understanding Spectrum Analyzers — ACLR (YouTube) — how ACLR is set up on a real analyzer. Everything from that video applied to your EXA/EXM.
What ACLR actually measures (the physics)
When a PA amplifies an OFDM signal, its nonlinearity creates intermodulation products. These fall at frequencies outside the original channel — in the adjacent channels. ACLR measures how much power leaked out: it is the ratio of the power in the adjacent channel to the power in the main channel, expressed in dBc (negative = adjacent is quieter). Higher dBc value = less leakage = better.
ACLR = 10×log₁₀(P_adjacent / P_carrier) [dBc, always negative] 3GPP limit for LTE Wide Area BS: E-UTRA offset (±1 carrier BW): ≥ 45 dBc UTRA offset (5/10 MHz offset): ≥ 50 dBc PW internal gate: typically 54–55 dBc (tighter than 3GPP)

VID3 Spectrum Analyzer Deep Dive — FFT, RBW, dynamic range, noise floor (YouTube rMVAQsUudSs) Intermediate click to expand▾

Spectrum analyser deep dive — FFT, RBW, VBW, dynamic range

RBW — Resolution Bandwidth:
RBW sets the width of the IF filter. Narrow RBW = fine frequency resolution, slow sweep, lower noise floor. Wide RBW = coarse resolution, fast sweep, higher noise floor. Rule: RBW ≤ signal bandwidth / 100 for spectrum mask tests. For ACLR: 100 kHz RBW (standard LTE measurement). For power: 1 MHz RBW OK. Never use RBW wider than the signal you are measuring.
VBW — Video Bandwidth and trace averaging:
VBW averages the detected power over time — reduces trace noise but does not affect measurement accuracy. VBW < RBW: smooth trace but slower. VBW = 3×RBW: typical for signals. VBW >> RBW: use for CW carriers. For noise floor measurements: reduce VBW to average out noise and see the true noise floor level clearly.
DANL — how to find the true noise floor:
DANL (Displayed Average Noise Level) is the EXA noise floor in dBm in the current RBW. DANL_total = DANL_per_Hz + 10·log(RBW). With preamp ON, 1 Hz RBW: DANL ≈ −130 dBm/Hz. At 100 kHz RBW: DANL = −130 + 50 = −80 dBm. If your signal is near this level, EXA is measuring its own noise — turn on preamp or narrow RBW. Your RX chain noise floor at 10 MHz BW: −98.25 dBm — well above EXA DANL.
▶ Watch: Understanding Spectrum Analyzers (YouTube) — FFT, RBW, dynamic range. Here is the complete teaching from that video.
How a spectrum analyzer works internally
A modern spectrum analyzer (your EXA N9010B) is a swept heterodyne receiver combined with an FFT engine. The signal is downconverted to IF, filtered (RBW filter), detected (RMS power detector), and the result plotted as power vs frequency. Modern instruments also do FFT-based analysis for speed.
RBW — the most important setting to understand
RBW (Resolution Bandwidth) = bandwidth of the IF filter before detection Effect on noise floor: Noise floor (dBm) = DANL + 10×log₁₀(RBW_Hz) EXA DANL ≈ −163 dBm/Hz (with preamp ON) RBW = 1 MHz: Noise floor = −163 + 60 = −103 dBm RBW = 100 kHz: Noise floor = −163 + 50 = −113 dBm ← ACLR standard RBW = 1 kHz: Noise floor = −163 + 30 = −133 dBm ← spurious search RBW = 100 Hz: Noise floor = −163 + 20 = −143 dBm ← phase noise meas
Narrower RBW = lower noise floor = can see weaker signals AND spurs. But narrower RBW = slower sweep (sweep time ∝ span/RBW²). For ACLR: 3GPP mandates 100 kHz RBW to match the integration bandwidth correctly. Using wrong RBW changes ACLR reading by exactly 10×log₁₀(RBW_used/RBW_correct).
VBW — Video Bandwidth (trace smoothing)
VBW is a post-detection filter that smooths the displayed trace. It does NOT change the noise floor — it only averages the noise fluctuations visually. Rule: VBW ≥ RBW always. Setting VBW < RBW suppresses noise peaks that could actually be real spurs — dangerous for spurious emission tests.
Dynamic range of a spectrum analyzer
Dynamic range = displayed range you can measure simultaneously without errors Limited from below: DANL (noise floor) — sets the minimum detectable signal Limited from above: mixer compression — too strong input causes clipping, false spurs Practical dynamic range: EXA with 30 dB attenuator: ≈ 70–80 dB simultaneous range EXA with 0 dB attenuator + preamp: ≈ 80–90 dB range but compression at −30 dBm input For ACLR of 55 dBc: if carrier = −15 dBm at EXA input, adjacent = −70 dBm Need noise floor below −70 dBm → use RBW 100 kHz → floor ≈ −113 dBm ✓
Sweep time — the trade-off
Swept analyzer sweep time ≥ k × Span / RBW² k ≈ 2 for most analyzers Example: Span = 100 MHz, RBW = 100 kHz → min sweep time = 2 × 100e6 / (100e3)² = 0.02 s = 20 ms Example: Span = 100 MHz, RBW = 10 kHz → min sweep time = 2 s (100× slower!)
Zero Span mode — time domain at one frequency
Setting Span = 0 Hz converts the spectrum analyzer into a power-vs-time recorder at one fixed frequency. Used for: viewing TDD frame structure (DL on, UL off), measuring PA switch-on transient, seeing DPD convergence in real time. Critical for B41 TDD debugging.
Noise figure of the spectrum analyzer itself
EXA N9010B typical DANL: Without preamp: −135 dBm/Hz (NF ≈ 39 dB — too noisy for sensitivity testing) With preamp: −163 dBm/Hz (NF ≈ 15 dB — usable for Rx sensitivity) For REFSENS test (−69 dBm in 10 MHz): Signal at EXA ≈ −69 − cable_loss dBm Need noise floor well below signal → always use preamp for Rx tests
The −174 dBm/Hz figure: this is thermal noise at room temperature (290K) — kTB where k=1.38×10⁻²³ J/K, T=290K, B=1 Hz → kT = 4×10⁻²¹ W = −174 dBm. Every 3 dB increase in temperature adds 3 dB to this floor. Every 10× bandwidth increase adds 10 dB. This is the absolute physical minimum noise any receiver can ever achieve.
VID4 RF Engineering Topics — signal chain, IQ, mixers (YouTube swjgr4YBhRM) Intermediate click to expand▾

RF engineering topics — signal chain, IQ, mixers

Signal chain mental model:
Every RF system is a chain of blocks: source → TX chain (gain up) → channel (loss) → RX chain (amplify) → ADC. dB rule: track power level through chain by adding gains (+) and losses (−) in dB. Noise figure accumulates — dominated by first lossy/noisy element. Dynamic range: difference between maximum signal and noise floor. Design goal: maintain signal > noise floor through entire chain from source to ADC.
IQ representation — why everything is I+Q:
Any narrowband RF signal can be written as: s(t) = I(t)cos(2πft) − Q(t)sin(2πft) where f is carrier frequency. I and Q capture full amplitude and phase information. Demodulation: multiply received signal by cos(2πft) and sin(2πft), low-pass filter → get I and Q separately. All modern radio systems — LTE, 5G, WiFi — use IQ representation internally. EXM generates IQ waveforms. EXA demodulates to IQ for constellation display.

The complete receiver signal chain — component by component
Antenna → Duplexer/Switch → BPF (image reject) → LNA → BPF (channel select) → VGA → Mixer+LO → BPF (IF/baseband) → ADC → DSP. Each stage has a specific job and adds specific impairments. Understanding this chain is the foundation of every RF test you run.
Why component ORDER in the chain matters so much
System NF dominated by FIRST stage (Friis): NF_sys ≈ NF_1 + (NF_2 − 1)/G_1 + ... Put a 3 dB attenuator BEFORE the LNA: NF_sys = 3 + (NF_LNA − 1)/0.5 ← the attenuator's loss is added directly If LNA NF = 2 dB, G = 20 dB: With attenuator: NF_sys ≈ 3 + (1.58−1)/0.5 = 3 + 1.16 = 4.16 dB Without attenuator: NF_sys ≈ 2 + tiny = 2.01 dB → The 3 dB attenuator before LNA costs 2.15 dB in system NF = significantly worse sensitivity
IQ architecture — how direct conversion works
In a direct-conversion (zero-IF) receiver, the LO runs exactly at the carrier frequency. Two mixers multiply the RF signal by the LO and by the LO shifted 90°, producing the I (in-phase) and Q (quadrature) baseband components. These are the two outputs of the ADC — both are needed to recover amplitude and phase information.
RF input: A·cos(2π·f_RF·t + φ) LO_I: cos(2π·f_RF·t) LO_Q: sin(2π·f_RF·t) ← 90° shifted I output = A·cos(φ) ← amplitude × cosine of phase Q output = A·sin(φ) ← amplitude × sine of phase From I and Q: amplitude = √(I²+Q²), phase = arctan(Q/I)
How IQ data relates to RSSI and dBFS
RSSI from IQ samples: P_IQ = (1/N) × Σ(I_n² + Q_n²) [linear, sum of squared amplitudes] RSSI_dBFS = 10×log₁₀(P_IQ / FS²) [relative to ADC full scale] Converting dBFS → dBm: RSSI_dBm = RSSI_dBFS + ADC_offset ADC_offset = known gain from antenna port to ADC input Example: RSSI_dBFS = −44.9 dBFS, ADC_offset = +50.6 dB (RF chain gain) RSSI_dBm = −44.9 + 50.6 = −(100 - 44.9 - 50.6) ... Actual calculation uses the ADC_ADJUST table in hardware.json ADC_ADJUST accounts for: RF gain, cable loss, analog filter, ADC scale factor This is why the calibration sets a fixed CW tone and measures the offset directly
