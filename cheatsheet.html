RF Power & dB

  • dBm↔mW: P(dBm)=10·log10(P/1mW); +3dB=×2, +10dB=×10, −3dB=½
  • dBm→W: 10^((dBm−30)/10). 0dBm=1mW, 30dBm=1W, 43dBm≈20W, 46dBm≈40W
  • Cascade: gains/losses add in dB. Friis NF: first stage (LNA) dominates system NF
  • 50Ω world; VSWR from return loss; ACLR/EVM are TX quality

Sensitivity & Noise

  • PREFSENS = −174 + 10log10(BW) + NF + IM + SNR (dBm)
  • kTB=−174 dBm/Hz · NF: 5(WideArea)/10(Medium)/13(Local) · IM=2 dB · SNR@95% throughput
  • 3GPP RefSens (f≤3GHz): 5/10/15/20MHz (A1-3) = −101.5 (36.104) / −100.8 (36.141)
  • RX combining gain: mid-band 4-RX ≈ +6 dB · low-band (B28) 2-RX ≈ +3 dB
  • Lower dBm = more sensitive = better. Pass = throughput ≥95% at ref level

⚠ Interview Traps

  • SIB reselection: LTE 3/4/5 · NR 2/3/4 (SIB2=radio cfg in LTE!)
  • IMSI 15 / IMEISV 16; auth compare = RES vs XRES; AUSF is 5G
  • PA = last TX stage · LNA = first RX stage (sets NF)
  • ACLR: higher=better (worst=min) · EVM: lower=better (worst=max)
  • B28 combining +3dB (2-RX) vs mid +6dB (4-RX) → B28 marginal first
  • X2/Xn must pre-exist before HO; target from A3 PCI→NRT/ANR
  • HO transparent containers: src→tgt = old RRC ctx; tgt→src = new RRCReconfig (dedicated RACH preamble, new C-RNTI)

Call Flows (1-liners)

  • RACH 4-step: Msg1 preamble → Msg2 RAR(TA+grant) → Msg3 RRC req → Msg4 contention res
  • Attach/Reg: RRC setup → Attach/Reg req → Auth → NAS security → ESM/PDU → Accept → Complete
  • PDU (5G): AMF→SMF→UPF (GTP-U tunnel), 5QI/QoS rules
  • Paging: AMF pages reg area; UE wakes at paging occasion (DRX)

Handovers

  • X2/Xn = direct RAN-RAN + data forwarding (fast, intra-AMF)
  • S1/NGAP(N2) = via core (no X2/Xn, or AMF/UPF reloc)
  • Flow: MeasReport(A3) → HO Req/Ack → RRCReconfig → RACH tgt → Complete → Path Switch
  • KPIs: too-late (RLF before HO) · too-early (HO then RLF/return) · wrong-cell
  • EN-DC: MeNB(LTE anchor)+SgNB(NR); SgNB Addition on B1 report; split bearer at PDCP

Voice

  • VoLTE: QCI5 (IMS sig) + QCI1 GBR (RTP voice); SPS for capacity
  • VoNR: native 5G voice (5QI1) · EPS Fallback: move to LTE when VoNR unavailable
  • CSFB: LTE→2G/3G for CS voice (RIM speeds redirect) · SRVCC: HO voice to 2G/3G

Scheduling / L2

  • SR (MAC, PUCCH) = ask UL grant · Service Req (NAS) = resume session
  • BSR = UL buffer per LCG (short/trunc/long) · PHR = Pmax−Pused
  • HARQ (PHY, fast, IR combining, 8 proc) vs ARQ (RLC AM, missing PDUs)
  • Scheduling: Dynamic (DCI/TTI) · SPS (VoLTE) · Persistent (rare)
  • DCI: 0_0/0_1 UL, 1_0/1_1 DL; on PDCCH, CCE=6 REG, blind decode

Debug Quick-Ref

  • Low throughput: RSRP/SINR/CQI → MCS/rank → BLER/HARQ → RB/scheduler → CA CCs → transport → UE cat/TCP → interference
  • Sensitivity short: normalise combining gain → pin FW → +5dB ADC atten (degrades=RX-gain issue; same=DU/demod) → change freq (interference)
  • HO failure: late/early trigger (A3/TTT/hysteresis) · target admit · RACH at tgt · path switch
  • VoLTE drop: RLF · SIP BYE/408 · QCI1 missing · DRX too aggressive · SRVCC late

Band Plan & RF Filters

  • Band ≠ carrier: a 3GPP band is a wide range; operator licenses a sub-block
  • RU front-end filters/duplexer are cut in HW for a fixed passband — no software retune
  • Carrier outside the designed passband → rejected / heavy roll-off → needs a HW filter variant
  • Band edge = higher insertion loss → less TX power, worse RX sensitivity (test low/mid/high)
  • e.g. B28: UL 703–748 / DL 758–803 MHz; variants (A/B) cover different sub-ranges
  • Edge often asymmetric: TX reaches sub-block, RX doesn't (Rx filter tighter, separate duplexer paths)
  • Diagnose edge: RB-tilt across channel (low RB > high RB) + collapse just outside + reproduces on other FW = HW filter
