RF Power & dB

  • dBm↔mW: P(dBm)=10·log10(P/1mW); +3dB=×2, +10dB=×10, −3dB=½
  • dBm→W: 10^((dBm−30)/10). 0dBm=1mW, 30dBm=1W, 43dBm≈20W, 46dBm≈40W
  • Cascade: gains/losses add in dB. Friis NF: first stage (LNA) dominates system NF
  • 50Ω world; VSWR from return loss; ACLR/EVM are TX quality

Sensitivity & Noise

  • PREFSENS = −174 + 10log10(BW) + NF + IM + SNR (dBm)
  • kTB=−174 dBm/Hz · NF: 5(WideArea)/10(Medium)/13(Local) · IM=2 dB · SNR@95% throughput
  • 3GPP RefSens (f≤3GHz): 5/10/15/20MHz (A1-3) = −101.5 (36.104) / −100.8 (36.141)
  • RX combining gain: mid-band 4-RX ≈ +6 dB · low-band (B28) 2-RX ≈ +3 dB
  • Lower dBm = more sensitive = better. Pass = throughput ≥95% at ref level

  • PA = last TX stage · LNA = first RX stage (sets NF)

  • HO transparent containers: src→tgt = old RRC ctx; tgt→src = new RRCReconfig (dedicated RACH preamble, new C-RNTI)

Call Flows (1-liners)

  • RACH 4-step: Msg1 preamble → Msg2 RAR(TA+grant) → Msg3 RRC req → Msg4 contention res
  • Attach/Reg: RRC setup → Attach/Reg req → Auth → NAS security → ESM/PDU → Accept → Complete
  • PDU (5G): AMF→SMF→UPF (GTP-U tunnel), 5QI/QoS rules
  • Paging: AMF pages reg area; UE wakes at paging occasion (DRX)

Handovers

  • X2/Xn = direct RAN-RAN + data forwarding (fast, intra-AMF)
  • S1/NGAP(N2) = via core (no X2/Xn, or AMF/UPF reloc)
  • Flow: MeasReport(A3) → HO Req/Ack → RRCReconfig → RACH tgt → Complete → Path Switch
  • KPIs: too-late (RLF before HO) · too-early (HO then RLF/return) · wrong-cell
  • EN-DC: MeNB(LTE anchor)+SgNB(NR); SgNB Addition on B1 report; split bearer at PDCP
  • X2 HO in pcap: on S1 only PathSwitchRequest/Ack (from target) = success; prep (HO Req/Ack, SN Status, UE Ctx Release) is on X2 (PPID 27). No Path Switch ⇒ HO not completed. Filters: s1ap.procedureCode==3, x2ap.procedureCode==0, gtp.message==254

Scheduling / L2

  • SR (MAC, PUCCH) = ask UL grant · Service Req (NAS) = resume session
  • BSR = UL buffer per LCG (short/trunc/long) · PHR = Pmax−Pused
  • HARQ (PHY, fast, IR combining, 8 proc) vs ARQ (RLC AM, missing PDUs)
  • Scheduling: Dynamic (DCI/TTI) · SPS (VoLTE) · Persistent (rare)
  • DCI: 0_0/0_1 UL, 1_0/1_1 DL; on PDCCH, CCE=6 REG, blind decode
  • 2CC test: each cell −3 dB (PA shared, sum = rated); per-UE vs 1CC KPI, total vs 2×1CC. 20 MHz: 1CC DL 270.4 / UL 44.1 Mbps; measured 588 / 130 total; CA +21%. Watch margins (CA 5 MHz UL +2%), cumulative NACK/DTX, UL RSSI rise

Debug Quick-Ref

  • Low throughput: RSRP/SINR/CQI → MCS/rank → BLER/HARQ → RB/scheduler → CA CCs → transport → UE cat/TCP → interference
  • Sensitivity short: normalise combining gain → pin FW → +5dB ADC atten (degrades=RX-gain issue; same=DU/demod) → change freq (interference)
  • HO failure: late/early trigger (A3/TTT/hysteresis) · target admit · RACH at tgt · path switch
  • VoLTE drop: RLF · SIP BYE/408 · QCI1 missing · DRX too aggressive · SRVCC late
  • Carrier activation: connect → In-Sync → SET_FREQ/freqConfigd → L1-Done/RRH-Ready → SET_TX_POWER → UPlaneConfig → ModifyPA → READY/ACTIVE. Breaks: PTP, per-band PE collision, not_synced drop, energy-saving TX-power, ModifyPA. Signature also in healthy hours ⇒ noise. Green cell? check RU carrier state → FH RX → KPI
  • Layer debug: nothing works ⇒ bottom-up (RU→PHY→PRACH→RRC→NAS→bearer/GTP-U); works poorly ⇒ compare the same metric across layers (eGTP/MAC/PDCP). NACK = decoded grant, bad data; DTX = no feedback (PDCCH/PUCCH). Rule out the harness

RCT / RU essentials

  • TX: ACLR (≥ limit, worst=min) · EVM · channel power · spectrum mask · DPD/CFR · PA efficiency
  • RX: RefSens · RSSI accuracy (CLI dBm/dBFS vs PHY) · dynamic range · PRACH detection (miss≤1%)
  • DSA/ADC_ADJUST, get-rssi (cli-manager telnet 8888), rct_stats (l1_Debug.log), gain budget
  • O-RAN 7.2x split; planes C/U/S/M; eCPRI; PTP/GNSS timing (S-plane)
  • Spectrum sensing: RU FFTs wideband IQ → PSD/spectrogram (RBW=Fs/N), waterfall over time; ship to SMO via M-plane (NETCONF/YANG), int16 deci-dBm to shrink size; for interference/incumbent/DSS
  • Power monitoring: RU self-reports power = DC input × PSU-efficiency correction; efficiency is load-dependent → use factory-measured LUT not datasheet; validate vs lab power analyzer; residual gap also = telemetry accuracy + −48V cable loss
  • DSA vs dBFS-adj: DSA = real atten before ADC (raises headroom/clip ceiling, noise floor & sensitivity unchanged); adc_dbfs_adj = reporting-only dBFS→dBm offset, must track DSA 1:1, calibrate on linear plateau (RSSI ≈ ±2 dB). Control test: DSA change moves RSSI but not sensitivity ⟹ fix the report, not the radio
  • uSleep test: saving comes from all-zero symbols (time), not "% RBs" (freq-domain 10% ⇒ ~0 W, correct). AAU power = Σ3 flavours × (PA rail + 12 V), get-PSU 1 s→1 min avg; PM CSV/5 min; ΔP=Poff−Pon at thermal steady state, same source, drop zero samples
  • Variable load: DPD must hold ACLR/EVM at every occupancy (100→0%); wait ~60 s re-convergence after any step. RX: keep max ≈ −15 dBFS; AGC 10 dB step ~−54 dBm; any atten change shifts dBFS 1:1 ⇒ RSSI offset must track (sensitivity unchanged)
  • DPD: IM3 grows 3 dB/dB ⇒ ACLR degrades 2 dB/dB; DPD buys ~15–20 dB. Memory polynomial Σakmx(n−m)|x(n−m)|k−1; ORX needs 3–5× BW + tight delay align; CFR before DPD; hard clip is unfixable; always compare DPD off vs on
  • ADC/DAC: 0 dBFS ≈ +2 dBm (this ADC); dBm@ant = dBFS + 2 − RX gain; keep ≤ −15 dBFS for PAPR. SNR=6.02N+1.76; NFADC=NSD+FS+174 ≈ 27 dB but ~33 dB gain ahead ⇒ +0.7 dB. Jitter SNR = −20log(2πf·tj). DAC: images k·Fs±f, sinc −3.9 dB @Fs/2
  • Line-up (B1 path): DAC −5 dBm → ~−50 dB cables/splitter/pads, +gain stages → PA +40.5 dB ⇒ 40.1 dBm → −1.7 dB coupler/circ/filter ⇒ 38.4 dBm. RX: −106 dBm → LNA (NF 0.55) → +32.8 dB total ⇒ −73 dBm at ADC; cascade NF 2.44 dB
  • PRACH placement: 6 RB = 1.08 MHz; FHGW reg in 625 Hz units (1 RB = 288): Reg = (prach_RB − NRB/2)·288 + 852 (5/10/15/20 MHz ⇒ 1284/3732/7044/10356). Move PRACH −10 RB ⇒ reg −2880 (5 MHz: −1596). Msg3 = PRACH+6
  • BBU↔RU lifecycle: POST+identity → DHCP → NETCONF call-home → caps (module-cap) → supervision → PTP LOCKED → config (PE/endpoints/array-carriers) → active ⇒ DAC/PA on → C-plane then U-plane per symbol → FM/PM/heartbeat. RU = low-PHY only; stall anywhere ⇒ carriers DISABLED
  • BW change: edit bw_mhz (Hz) in on_the_fly_configs.json → reboot (startup.xml is regenerated, never edit it) → verify startup.xml, sysrepo running, OBW. Caps: 5–20 MHz/carrier, 2 carriers, 40 MHz total
  • J-Link flash: unit powered & booted; 5-pin RESET/SWDIO/GND/SWCLK/VTref → J-Link 15/7/4/9/1; JFlashLite: select MCU, .bin at 0x00000000, Program → "Done." → power-cycle, verify version. VTref = voltage sense, not supply

Conformance Limits (3GPP)

  • TX dyn range = OSTP(E-TM3.1)−OSTP(E-TM2) = 10log₁₀(N_RB): 5/10/15/20 = 13.9/16.9/18.7/20.0 dB min-req; test-req = −0.4 TT → 16.5/18.3/19.6 (report both; a=256QAM,b=1024QAM pairs)
  • ACLR ≥ 45 dB (worst=min, pass=min−0.8) · EVM ≤ per-ETM (QPSK 8%, worst=max)
  • OFF power <−85 dBm/MHz · transient <10µs · TAE <90ns · spurious ≤−36dBm
  • RefSens = −174+10log₁₀(BW)+NF+IM+SNR; pass if UL_input < KPI(=base+DSA)
  • RX dyn range C/N = −69.9 − noise(BW) + 10log₁₀(BW_cfg/4.5)
  • PRACH miss% = (window−detected)/window×100, pass ≤1% · RRH gain = RSSI−UL_rx+10log₁₀(12·N_RB)
  • ACLR vs EVM: ACLR bad + EVM bad ⇒ compression/DPD; ACLR OK + EVM bad ⇒ CFR/phase noise/IQ/floor. EVM≈1/√SNR (8%≈22 dB, 3.5%≈29 dB). LTE ACLR = 45 dBc or −13 dBm/MHz (Cat A), whichever less stringent ⇒ ~40 dBc at 20 MHz

Band Plan & RF Filters

  • Band ≠ carrier: a 3GPP band is a wide range; operator licenses a sub-block
  • RU front-end filters/duplexer are cut in HW for a fixed passband — no software retune
  • Carrier outside the designed passband → rejected / heavy roll-off → needs a HW filter variant
  • Band edge = higher insertion loss → less TX power, worse RX sensitivity (test low/mid/high)
  • e.g. B28: UL 703–748 / DL 758–803 MHz; variants (A/B) cover different sub-ranges
  • Edge often asymmetric: TX reaches sub-block, RX doesn't (Rx filter tighter, separate duplexer paths)
  • Diagnose edge: RB-tilt across channel (low RB > high RB) + collapse just outside + reproduces on other FW = HW filter
